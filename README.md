# WTZP2 Two-Phase Order Design

This repository contains the manuscript source, compiled PDF, and reproducibility files for the paper:

**A two-phase order design problem for variable-order fractional operators: relaxation, placement and homogenized kernels**

The work studies a two-phase spectral design problem in which the design variable is the fractional order of a nonlocal Dirichlet form. It develops the variational framework, relaxation analysis, placement rules, homogenized-kernel mechanism, Hardy-exchange admissibility conditions, and reproducible one-dimensional numerical evidence.

## Contents

- `manuscript/`: compiled manuscript PDF and LaTeX source.
- `reproducibility_code/`: Python scripts, CSV tables, and manifest files used to reproduce the reported numerical checks.
- `submission_docs/`: cover letter draft, declarations, highlights, checklist, and metadata notes.

## Reproducibility

The numerical appendix can be checked using the scripts in `reproducibility_code/`. The reported tables are stored as CSV files, with a JSON manifest documenting the table-generation files.
